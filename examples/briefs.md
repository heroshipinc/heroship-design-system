# Briefs for effective AI work
## Responsive webpage
Read the Heroship guide. Create [page] for [audience] with [goal]. Use this approved copy: [copy]. Available assets: [list]. Use [light/dark] mode, mobile heading styles at narrow widths, and one main CTA: [label]. Return the artifact, font/asset substitutions, and results of the quality checklist. Do not invent metrics or testimonials.

## Marketing email
Create a 600px email about [topic] using supplied copy and one primary CTA. Follow Heroship typography and restrained color rules. Use system fallbacks where needed, solid alternatives to effects, and readable mobile padding. Identify email-client tests still required.

## Social carousel
Create [number] slides at [dimensions] for [audience]. Each slide should communicate one idea. Use the same exact secondary shade throughout, a consistent grid and clear hierarchy. Use approved supplied imagery or labeled placeholders. Confirm crop assumptions and inspect at likely viewing size.

## Review existing work
Compare this artifact with the guide. Prioritize concrete deviations in typography, palette, contrast, logo geometry, spacing and buttons. Distinguish hard-rule violations from optional improvements. Do not reject horizontal gradients or readable text directly on gradients.

## Delivery response
Provide the artifact, a concise explanation of major choices, actual fonts used, missing approved assets, checks performed and any proposed values that still need approval.
