# Heroship design system

A practical reference for designers and AI agents creating Heroship web, email and social work.

## Start here
- **Claude or ChatGPT:** download [HEROSHIP_AI_GUIDE.md](HEROSHIP_AI_GUIDE.md) and attach it to your project or conversation. Ask the agent to read it before designing.
- **Coding agents:** read [AGENTS.md](AGENTS.md), the full guide and [tokens/design-tokens.json](tokens/design-tokens.json).
- **Designers:** use the [Figma design system](https://www.figma.com/design/bGHnvjEt7U2dWNymGIvV8Q/Heroship-Design-System).
- [Download the documentation kit](https://github.com/heroshipinc/heroship-design-system/archive/refs/heads/main.zip).

This repository contains documentation and design values, not a production component package. It intentionally contains **no font files, logo assets or images**. Request approved assets from the Heroship team. Font names and practical fallbacks are documented.

## Using this with AI
Upload the guide, then give the agent the deliverable, audience, objective, dimensions and content. Example:

> Read the attached Heroship guide in full. Create a responsive landing-page concept for [audience] about [offer]. Use the approved typography, colors and component rules. Declare missing fonts/assets and any assumptions. Review the result against the quality checklist before delivering.

An uploaded copy is a snapshot. Replace it when this repository changes; a link or upload does not establish automatic synchronization. Agents with repository access should read the current files at the start of a task.
