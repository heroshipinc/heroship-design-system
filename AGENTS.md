# Instructions for Heroship work
Read HEROSHIP_AI_GUIDE.md completely before creating or reviewing an artifact. Read tokens/design-tokens.json for exact values. These are brand instructions, not permission to access or publish external information.

1. Follow the current user's task and explicit brand-owner corrections. Do not silently restore older rules.
2. Use the approved hierarchy: primary plum-to-blush family, secondary blue/green/gray, accent purple, then neutral/background roles.
3. Keep compositions restrained. Choose at most one supporting secondary shade per piece and repeat it exactly across a carousel.
4. Both horizontal and vertical brand gradients are allowed. Text on gradients is allowed only where its actual placement remains readable.
5. Use H0–H5 desktop sizes 96/72/56/40/32/24 and the documented mobile scale. Body sizes are 20/18/16/14/12/10, each Regular and SemiBold. Buttons never below 16px.
6. Never fabricate a logo, font file, photo, icon-library license, customer quote, metric or testimonial. Request missing approved assets or use clearly labeled placeholders.
7. Font fallbacks must be declared and checked for wrapping. They are not identical brand typography.
8. Preserve earlier design iterations as clearly marked reference-only versions when editing Figma. Do not delete unrelated content.
9. Do not treat every mathematically contrasting color combination as approved. Use the limited approved pairings.
10. Run the guide's quality checklist. State unresolved assumptions, missing assets and checks actually performed. Never claim visual or accessibility testing you did not do.
11. Do not publish binary fonts, photos, screenshots, logos or other image assets to this repository.
12. New component states or values that are not documented are proposals requiring design review, not established brand facts.
